## 돌발 답변 공통 구조

### 묘사·소개

`주제 직접 제시 → 사람들이 사용하는 방식 → 내 경험 → 장단점 → 결론`

### 과정

`준비 → 분류·진행 → 마무리 → 주의할 점`

### 경험

`언제·어디서 → 문제 발생 → 대응 → 결과 → 교훈`

### 비교

`과거 → 가장 큰 차이 → 현재 → 장단점 → 개인 의견`
