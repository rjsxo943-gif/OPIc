# 기술 - 과거와 현재 기술 비교

## Question

- How has technology changed over the years?
- What was technology like in the past?
- How is it different now?

---

## Speaking Order

어릴 때는 집의 데스크톱을 사용함

↓

컴퓨터가 느리고 한 장소에서만 사용 가능

↓

현재는 스마트폰·노트북·태블릿 사용

↓

어디서나 파일과 정보에 접근 가능

↓

편리하지만 기술 의존도가 높아짐

---

## Full Script

Technology has changed dramatically / since I was a child.

When I was younger, / my family mainly used / one desktop computer at home. / It was large, slow, / and fixed in one place.

If someone else was using it, / I had to wait / for my turn. / The internet was also slower, / and it took much longer / to download files / or watch videos.

I mainly used the computer / for simple games, YouTube, / and school assignments.

These days, / the situation is completely different. / I have a smartphone and a laptop, / so I can study, communicate, / and watch videos / almost anywhere.

I can also save files online / and open them / on different devices. / For example, / I can write notes / on my laptop / and later read them / on my tablet or smartphone.

Searching for information / has become much faster as well. / In the past, / I had to sit / in front of a computer / and search several websites.

Now, / I can find most information / within seconds / using my phone.

The biggest change is / that technology is no longer something / we use only at a desk. / It follows us everywhere / and has become part of / almost every activity.

Of course, / this convenience has made people / more dependent on technology. / When the internet is slow / or a device stops working, / even a simple task / can become frustrating.

Still, / I prefer modern technology / because it saves time / and allows me to work / much more efficiently.

---

## 직독직해

기술은 극적으로 변해 왔다 / 내가 어렸을 때부터.

내가 더 어렸을 때, / 우리 가족은 주로 사용했다 / 집에서 데스크톱 컴퓨터 한 대를. / 그것은 크고 느렸고, / 한 장소에 고정되어 있었다.

다른 누군가가 그것을 사용하고 있다면, / 나는 기다려야 했다 / 내 차례를. / 인터넷도 더 느렸고, / 훨씬 더 오래 걸렸다 / 파일을 다운로드하거나 / 영상을 보는 데.

나는 주로 그 컴퓨터를 사용했다 / 간단한 게임과 YouTube, / 그리고 학교 과제를 위해.

요즘에는, / 상황이 완전히 다르다. / 나는 스마트폰과 노트북을 가지고 있어서, / 공부하고, 소통하고, / 영상을 볼 수 있다 / 거의 어디서든.

나는 또한 파일을 온라인에 저장할 수 있고 / 그것들을 열 수 있다 / 다른 기기들에서. / 예를 들어, / 나는 메모를 작성할 수 있다 / 내 노트북에서 / 그리고 나중에 그것들을 읽을 수 있다 / 내 태블릿이나 스마트폰에서.

정보를 찾는 것은 / 훨씬 더 빨라지기도 했다. / 과거에는, / 나는 앉아 있어야 했다 / 컴퓨터 앞에 / 그리고 여러 웹사이트를 검색해야 했다.

지금은, / 나는 대부분의 정보를 찾을 수 있다 / 몇 초 안에 / 내 휴대전화를 사용해서.

가장 큰 변화는 / 기술이 더 이상 어떤 것이 아니라는 것이다 / 우리가 책상에서만 사용하는. / 그것은 우리를 어디든 따라다니고 / 일부가 되었다 / 거의 모든 활동의.

물론, / 이런 편리함은 사람들을 만들었다 / 기술에 더 의존하도록. / 인터넷이 느리거나 / 기기가 작동을 멈추면, / 심지어 간단한 일도 / 답답해질 수 있다.

그래도, / 나는 현대 기술을 더 선호한다 / 왜냐하면 그것은 시간을 절약하고 / 내가 일할 수 있게 해 주기 때문이다 / 훨씬 더 효율적으로.
