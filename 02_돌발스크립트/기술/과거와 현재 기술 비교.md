# 기술 - 과거와 현재 기술 비교

## Question

- How has technology changed over the years?
- What was technology like in the past?
- How is it different now?

---

## Speaking Order

과거 데스크톱 → 느리고 불편함 → 현재 스마트폰·노트북 → 어디서나 사용 → 편리하지만 의존도 증가

---

## Full Script

Technology has changed a lot / since I was a child.

When I was younger, / my family used / one desktop computer / at home.

It was big and slow, / and I could only use it / in one place.

If someone else was using it, / I had to wait / for my turn.

These days, / things are completely different.

I use / a smartphone and a laptop, / so I can study, / watch videos, / and search for information / almost anywhere.

I can also save files online / and open them / on different devices.

For me, / the biggest change is convenience.

Of course, / people depend on technology / much more than before.

Still, / I prefer modern technology / because it saves time / and makes my life easier.

---

## 직독직해

기술은 많이 변했다 / 내가 어렸을 때부터.

내가 더 어렸을 때, / 우리 가족은 사용했다 / 데스크톱 컴퓨터 한 대를 / 집에서.

그것은 크고 느렸고, / 나는 그것을 사용할 수 있었다 / 한 장소에서만.

다른 누군가가 그것을 사용하고 있으면, / 나는 기다려야 했다 / 내 차례를.

요즘에는, / 상황이 완전히 다르다.

나는 사용한다 / 스마트폰과 노트북을, / 그래서 나는 공부하고, / 영상을 보고, / 정보를 검색할 수 있다 / 거의 어디서든.

나는 또한 파일을 온라인에 저장하고 / 그것들을 열 수 있다 / 다른 기기들에서.

나에게, / 가장 큰 변화는 편리함이다.

물론, / 사람들은 기술에 의존한다 / 예전보다 훨씬 더 많이.

그래도, / 나는 현대 기술을 더 좋아한다 / 왜냐하면 그것은 시간을 아껴주고 / 내 삶을 더 쉽게 만들기 때문이다.

---

## Key Expressions

- wait for my turn
- things are completely different
- almost anywhere
- depend on technology
- make my life easier
