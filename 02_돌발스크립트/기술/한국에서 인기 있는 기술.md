# 기술 - 한국에서 인기 있는 기술

## Question

- Tell me about a popular technology in your country.
- Why is it popular?
- How do people use it?

---

## Speaking Order

스마트폰 소개 → 주요 기능 → 내가 쓰는 방법 → 장점 → 단점

---

## Full Script

One of the most popular technologies / in Korea / is the smartphone.

Almost everyone has one, / and people use it / every day.

People use smartphones / to send messages, / watch YouTube, / use maps, / and make payments.

I use mine / all the time / as well.

I use it / to talk with friends, / listen to music, / and search for information / when I study.

It is also very useful / when I travel / because I can use maps / and translation apps.

That is why / smartphones are so popular / in Korea.

The only problem is / that people sometimes spend / too much time / on their phones.

Still, / I think smartphones are very useful / because one small device / can do so many things.

---

## 직독직해

가장 인기 있는 기술들 중 하나는 / 한국에서 / 스마트폰이다.

거의 모든 사람이 하나를 가지고 있고, / 사람들은 그것을 사용한다 / 매일.

사람들은 스마트폰을 사용한다 / 메시지를 보내고, / YouTube를 보고, / 지도를 사용하고, / 결제하기 위해.

나도 내 스마트폰을 사용한다 / 항상 / 마찬가지로.

나는 그것을 사용한다 / 친구들과 이야기하고, / 음악을 듣고, / 정보를 검색하기 위해 / 내가 공부할 때.

그것은 또한 매우 유용하다 / 내가 여행할 때 / 왜냐하면 나는 지도를 사용하고 / 번역 앱을 사용할 수 있기 때문이다.

그것이 이유다 / 스마트폰이 그렇게 인기 있는 / 한국에서.

유일한 문제는 / 사람들이 가끔 보낸다는 것이다 / 너무 많은 시간을 / 휴대전화에.

그래도, / 나는 스마트폰이 매우 유용하다고 생각한다 / 왜냐하면 작은 기기 하나가 / 정말 많은 것을 할 수 있기 때문이다.

## Key Expressions

- almost everyone
- all the time
- translation apps
- too much time
- so many things
