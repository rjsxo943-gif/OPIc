# 재활용 - 우리나라의 재활용 제도

## Question

- Tell me about the recycling system in your country.
- How do people recycle?
- What do people separate?

---

## Speaking Order

분리수거 소개 → 종류별 분류 → 배출 방법 → 장점 → 불편한 점

---

## Full Script

Recycling is very common / in Korea.

People usually separate / paper, plastic, glass, / cans, and food waste.

At my apartment, / there is a recycling area / where people take these items.

Before throwing things away, / I usually rinse bottles and cans / and separate them / by type.

Cardboard boxes are also folded / so they do not take up / too much space.

Food waste is handled / separately / from regular trash.

At first, / the system can feel a little complicated, / but once you get used to it, / it is not difficult.

I think the system is useful / because it reduces waste / and keeps the neighborhood cleaner.

The only annoying part is / that separating everything / takes a little extra time.

Still, / I think recycling is an important habit / and most people in Korea / are used to doing it.

---

## 직독직해

재활용은 매우 흔하다 / 한국에서.

사람들은 보통 분리한다 / 종이, 플라스틱, 유리, / 캔, 그리고 음식물 쓰레기를.

내 아파트에는, / 분리수거장이 있다 / 사람들이 이런 물건들을 가져가는.

물건들을 버리기 전에, / 나는 보통 병과 캔을 헹구고 / 그것들을 분리한다 / 종류별로.

박스들도 접는다 / 그것들이 차지하지 않도록 / 너무 많은 공간을.

음식물 쓰레기는 처리된다 / 따로 / 일반 쓰레기와.

처음에는, / 이 제도가 조금 복잡하게 느껴질 수 있지만, / 익숙해지고 나면, / 어렵지 않다.

나는 이 제도가 유용하다고 생각한다 / 왜냐하면 쓰레기를 줄이고 / 동네를 더 깨끗하게 유지하기 때문이다.

유일하게 귀찮은 점은 / 모든 것을 분리하는 것이 / 약간의 추가 시간이 든다는 것이다.

그래도, / 나는 재활용이 중요한 습관이라고 생각하고 / 한국의 대부분 사람들은 / 그것에 익숙하다.

## Key Expressions

- separate by type
