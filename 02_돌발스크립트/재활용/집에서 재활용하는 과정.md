# 재활용 - 집에서 재활용하는 과정

## Question

- Tell me how you recycle at home.
- What steps do you usually follow?
- Describe the process in detail.

---

## Speaking Order

집에서 재활용품을 따로 모음

↓

용기를 비우고 씻음

↓

페트병 라벨과 상자 테이프 제거

↓

분리수거장으로 옮김

↓

귀찮지만 일상적인 습관이 됨

---

## Full Script

At home, / I try to separate recyclable items / before they pile up too much.

I normally keep / paper and cardboard / in one area, / and I use a separate bag / for plastic bottles, cans, / and glass containers.

Before putting food containers or plastic bottles / into the recycling bag, / I empty anything left inside / and rinse them / with water.

If they are dirty, / they may not be recycled properly, / so I try to clean them / as soon as I finish using them.

I also remove the labels / from plastic bottles.

For cardboard boxes, / I take off the tape, / flatten the boxes, / and stack them together.

When the bags become full, / I take everything / to the recycling area / near my building.

There are different containers / for paper, plastic, metal cans, / glass, / and vinyl.

I check the signs / and place each item / in the correct container. / Regular trash and food waste / are thrown away / separately.

Honestly, / the most annoying part / is washing containers / and removing labels.

Sometimes / I feel too tired / to do it immediately, / so the recycling starts / to pile up.

Still, / I try not to wait too long / because it becomes much more difficult / when there is a large amount.

Recycling takes / a little extra effort, / but I have done it / for so long / that it has become / part of my normal household routine.

## 직독직해

집에서, / 나는 재활용품을 분리하려고 한다 / 너무 많이 쌓이기 전에.

나는 보통 둔다 / 종이와 박스를 / 한 공간에, / 그리고 별도의 봉지를 사용한다 / 플라스틱 병과 캔, / 그리고 유리 용기를 위해.

음식 용기나 플라스틱 병을 넣기 전에 / 재활용 봉투에, / 나는 안에 남은 것을 비우고 / 그것들을 헹군다 / 물로.

그것들이 더럽다면, / 제대로 재활용되지 않을 수도 있어서, / 나는 그것들을 씻으려고 한다 / 사용을 끝내자마자.

나는 또한 라벨을 제거한다 / 플라스틱 병에서.

박스의 경우에는, / 나는 테이프를 떼고, / 박스를 납작하게 만들고, / 함께 쌓아 둔다.

봉지들이 가득 차면, / 나는 모든 것을 가져간다 / 분리수거장으로 / 우리 건물 근처의.

서로 다른 수거함들이 있다 / 종이, 플라스틱, 금속 캔, / 유리, / 그리고 비닐을 위한.

나는 표지판을 확인하고 / 각각의 물건을 넣는다 / 맞는 수거함에. / 일반 쓰레기와 음식물 쓰레기는 / 버려진다 / 따로.

솔직히, / 가장 귀찮은 부분은 / 용기를 씻고 / 라벨을 제거하는 것이다.

가끔 / 나는 너무 피곤하다고 느낀다 / 그것을 바로 하기에, / 그래서 재활용품이 시작한다 / 쌓이기.

그래도, / 나는 너무 오래 기다리지 않으려고 한다 / 왜냐하면 훨씬 더 어려워지기 때문이다 / 양이 많아지면.

재활용은 필요로 한다 / 약간의 추가 노력을, / 하지만 나는 그것을 해 왔다 / 아주 오랫동안 / 그래서 그것은 되어 버렸다 / 내 평범한 집안 루틴의 일부가.
