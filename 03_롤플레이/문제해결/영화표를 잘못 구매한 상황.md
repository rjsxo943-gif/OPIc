# 롤플레이 - 영화표를 잘못 구매한 상황

## Situation

영화표 시간을 잘못 샀다. 직원에게 문제를 설명하고 해결책을 제시한다.

---

## Speaking Order

문제 설명 → 교환 요청 → 환불 요청 → 마무리

---

## Full Script

Excuse me. / I have a problem / with my movie tickets.

I accidentally bought tickets / for tonight, / but I need tickets / for tomorrow.

Would it be possible / to change them / to tomorrow's show?

Any evening time / would be fine / for me.

If that is not possible, / could I get / a refund instead?

Then I can buy / new tickets / for tomorrow.

I’m sorry / about the mistake.

Could you please check / what I can do?

Thank you / for your help.

---

## 직독직해

실례합니다. / 문제가 있어요 / 제 영화표에.

제가 실수로 표를 샀어요 / 오늘 밤 것으로, / 하지만 저는 표가 필요해요 / 내일 것으로.

가능할까요 / 그것들을 바꾸는 것이 / 내일 상영으로?

어떤 저녁 시간이든 / 괜찮아요 / 저에게는.

그게 가능하지 않다면, / 제가 받을 수 있을까요 / 대신 환불을?

그러면 저는 살 수 있어요 / 새 표를 / 내일 것으로.

죄송합니다 / 실수해서.

확인해 주실 수 있나요 / 제가 무엇을 할 수 있는지?

감사합니다 / 도와주셔서.

---

## Key Expressions

- I accidentally bought...
- Would it be possible to change them?
- If that is not possible...
- Could I get a refund instead?
