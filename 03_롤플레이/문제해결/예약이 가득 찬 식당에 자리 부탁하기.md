# 롤플레이 - 예약이 가득 찬 식당에 자리 부탁하기

## Situation

어머니 생신에 가족 네 명이 식당에 가려고 하지만 원하는 시간이 만석이다. 다른 방법을 요청한다.

---

## Speaking Order

예약 요청 → 만석 확인 → 다른 시간 → 대기 명단 → 마무리

---

## Full Script

Hello, / I'd like to make a reservation / for this Saturday evening.

There will be / four people, / and we were hoping / to come at seven.

Oh, / you're fully booked / at that time?

I see. / It's my mother's birthday, / so I'd really like / to bring my family there.

Could we come / a little earlier / or later instead?

For example, / five thirty / or after eight / would be okay.

If those times are also full, / could you put my name / on the waiting list?

Please call me / if a table becomes available.

Thank you / for checking. / I really appreciate / your help.

---

## 직독직해

안녕하세요, / 저는 예약하고 싶어요 / 이번 주 토요일 저녁으로.

저희는 / 네 명이고, / 우리는 바라고 있었어요 / 7시에 가기를.

아, / 예약이 다 찼나요 / 그 시간에?

그렇군요. / 제 어머니 생신이라서, / 저는 정말 모시고 가고 싶어요 / 제 가족을 그곳에.

우리가 갈 수 있을까요 / 조금 더 이르게 / 또는 더 늦게 대신?

예를 들어, / 5시 30분이나 / 8시 이후도 / 괜찮아요.

그 시간들도 다 찼다면, / 제 이름을 올려주실 수 있나요 / 대기 명단에?

전화해 주세요 / 자리가 생기면.

감사합니다 / 확인해 주셔서. / 정말 감사해요 / 도와주셔서.

---

## Key Expressions

- We're hoping to come at seven.
- Could we come earlier or later instead?
- Put my name on the waiting list.
- If a table becomes available...
