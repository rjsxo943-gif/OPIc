# 롤플레이 - 잘못된 가구가 배송된 상황

## Situation

가구점에서 검정색 싱글 침대와 특정 모델의 소파를 주문했다.

하지만 흰색 침대와 주문하지 않은 다른 모델의 소파가 배송되었다.

가구점에 전화해서 문제를 설명하고 해결책을 두세 가지 제시한다.

---

## Speaking Order

검정색 침대와 특정 소파 모델을 주문함

↓

흰색 침대와 다른 소파 모델이 배송됨

↓

원래 주문한 제품으로 교환 및 재배송 요청

↓

바로 교환할 수 없다면 가장 빠른 배송 날짜 문의

↓

소파는 할인해 주면 현재 모델을 사용할 수도 있음

↓

침대 교환이 불가능하면 전액 환불 요청

↓

확인 후 다시 연락해 달라고 부탁

---

## Full Script

Hello, / is this the customer service department / at the furniture store?

Hi, / I’m calling / because there seems to be a problem / with the furniture I ordered.

I ordered / a black single bed / and a specific model of gray sofa, / but the items that arrived today / are not what I ordered.

The bed is white / instead of black, / and the sofa is / a completely different model.

Unfortunately, / I was not home / when the furniture was delivered, / so the delivery workers had already left / by the time I checked everything.

First of all, / could you please pick up / the incorrect furniture / and deliver / the items I originally ordered?

I recently moved / into a new apartment, / and I do not have / any other furniture to use, / so I would really appreciate it / if you could replace them / as soon as possible.

Oh, / I see.

If the correct items are not available / right away, / could you tell me / the earliest possible delivery date?

I can wait / a few days, / but I would prefer / to receive them / by this weekend.

Okay, / that would work / for me.

If replacing the sofa soon / is not possible, / I have another suggestion.

The sofa is a different model, / but it still looks comfortable. / I might be willing to keep it / if you can offer me / a reasonable discount.

However, / I cannot keep the bed / because the white color is completely different / from the black one I ordered.

If you cannot exchange the bed, / I would like to return it / and receive / a full refund.

I’m sorry / for the trouble, / but I hope / we can solve this problem / as soon as possible.

Could you please check / my order details / and call me back / with the available options?

Thank you / for your help.

## 대안 구조

### 대안 1 - 교환 및 재배송

Could you pick up the incorrect furniture and deliver the items I originally ordered?

### 대안 2 - 가장 빠른 배송 일정

If the correct items are not available right away, could you tell me the earliest possible delivery date?

### 대안 3 - 소파 할인 또는 침대 환불

I might be willing to keep the sofa if you can offer me a reasonable discount.

If you cannot exchange the bed, I would like to return it and receive a full refund.

## Notes

- 침대 설정은 `검정색 주문 → 흰색 배송`으로 끝까지 유지한다.
- 소파 설정은 `주문한 모델 → 다른 모델 배송`으로 끝까지 유지한다.
- 소파는 사용할 수 있는 제품이므로 할인이라는 타협안을 제시한다.
- 침대는 색상이 완전히 다르므로 교환이 불가능하면 환불을 요청한다.
- 핵심 순서는 `교환 → 배송 일정 → 소파 할인 / 침대 환불`이다.
