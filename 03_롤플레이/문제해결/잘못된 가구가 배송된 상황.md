# 롤플레이 - 잘못된 가구가 배송된 상황

## Situation

검정색 침대와 특정 소파를 주문했지만 다른 제품이 배송됐다. 교환과 다른 해결책을 요청한다.

---

## Speaking Order

문제 설명 → 교환 요청 → 배송 날짜 → 환불/할인 → 마무리

---

## Full Script

Hello, / I'm calling / because there is a problem / with my order.

I ordered / a black bed / and a gray sofa, / but I received / the wrong items.

The bed is white, / and the sofa is / a different model.

Could you please / pick them up / and send me / the correct items?

If they are not available / right away, / when is the earliest / you can deliver them?

I can wait / a few days, / but I need them / as soon as possible.

If you cannot replace the bed, / I would like / a full refund.

For the sofa, / I could keep it / if you can give me / a discount.

Could you please check / my order / and call me back?

Thank you / for your help.

---

## 직독직해

안녕하세요, / 저는 전화드렸어요 / 문제가 있기 때문에 / 제 주문에.

저는 주문했어요 / 검정색 침대와 / 회색 소파를, / 하지만 저는 받았어요 / 잘못된 물건들을.

침대는 흰색이고, / 소파는 / 다른 모델이에요.

해주실 수 있나요 / 그것들을 회수하고 / 저에게 보내주는 것을 / 맞는 물건들을?

그것들이 가능하지 않다면 / 바로, / 가장 빠른 때가 언제인가요 / 배송할 수 있는?

저는 기다릴 수 있어요 / 며칠은, / 하지만 저는 그것들이 필요해요 / 가능한 한 빨리.

침대를 교환할 수 없다면, / 저는 원해요 / 전액 환불을.

소파는, / 제가 그냥 사용할 수도 있어요 / 만약 주실 수 있다면 / 할인을.

확인해 주실 수 있나요 / 제 주문을 / 그리고 다시 전화해 주실 수 있나요?

감사합니다 / 도와주셔서.

---

## Key Expressions

- I received the wrong items.
- Could you send me the correct items?
- When is the earliest you can deliver them?
- I would like a full refund.
- I could keep it if...
