# 롤플레이 - 사고 싶은 가구에 대해 질문하기

## Situation

가구점에 전화해서 사고 싶은 책상에 대해 질문하기.

---

## Speaking Order

인사 → 가격 → 크기 → 배송 → 마무리

---

## Full Script

Hi, / I'm calling about a desk / I saw on your website.

I have a few questions / before I buy it.

First, / how much is it / right now?

Also, / what are the dimensions? / I live in a small studio apartment, / so I need to check the size.

And one more thing, / do you offer delivery?

If so, / how long does delivery usually take?

Okay, / that sounds good.

Thanks for your help. / I'll think about it / and call you back.

---

## 직독직해

안녕하세요, / 저는 책상에 대해 전화드렸어요 / 제가 웹사이트에서 본.

저는 몇 가지 질문이 있어요 / 그것을 사기 전에.

먼저, / 가격이 얼마인가요 / 지금?

또한, / 크기가 어떻게 되나요? / 저는 작은 스튜디오 아파트에 살아서, / 크기를 확인해야 해요.

그리고 한 가지 더, / 배송을 해주시나요?

그렇다면, / 배송은 보통 얼마나 걸리나요?

좋아요, / 괜찮네요.

도와주셔서 감사합니다. / 생각해 보고 / 다시 전화드릴게요.

---

## Key Questions

- How much is it?
- What are the dimensions?
- Do you offer delivery?
- How long does delivery take?
