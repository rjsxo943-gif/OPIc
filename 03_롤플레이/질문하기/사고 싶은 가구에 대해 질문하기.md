# 롤플레이 - 사고 싶은 가구에 대해 질문하기

## Situation

새 아파트로 이사해서 침대, 소파, 테이블을 사려고 가구 매장을 방문한 상황이다.

판매 직원에게 제품의 종류, 가격, 배송 서비스, 할인에 관해 질문한다.

---

## Speaking Order

인사와 상황 설명

↓

싱글 침대 종류와 가격 질문

↓

작은 집에 맞는 소파와 테이블 질문

↓

배송과 조립 서비스 질문

↓

묶음 할인 질문

↓

감사 인사 후 마무리

---

## Full Script

Hi, / I just moved / into a small studio apartment, / so I need to buy / a few pieces of furniture.

Could I ask you / a few questions?

First, / what kinds of single beds / do you have?

I live alone, / so I’m looking for / something simple / and not too large.

Oh, I see. / That one looks nice.

How much is it, / and does the price include / the mattress?

Okay, / that’s good to know.

Also, / do you have a comfortable sofa / that would fit / in a small studio?

I think / a two-seat sofa / would be best / for me.

That sounds good. / Do you have / a small coffee table / that matches it?

One more thing. / Do you offer / delivery and assembly services?

It would be hard / for me / to carry and assemble everything / by myself.

Great. / Finally, / are there any discounts / if I buy the bed, sofa, and table / together?

Oh, there are? / That sounds like / a good deal.

Thank you / for answering all my questions. / You’ve been / very helpful.

I’ll look around / a little more / and let you know / when I make my decision.

Thanks again.

## 핵심 질문

### 침대

- What kinds of single beds do you have?
- How much is it?
- Does the price include the mattress?

### 소파와 테이블

- Do you have a comfortable sofa that would fit in a small studio?
- Do you have a small coffee table that matches it?

### 배송과 조립

- Do you offer delivery and assembly services?

### 할인

- Are there any discounts if I buy the bed, sofa, and table together?

---

## 핵심 표현

- move into a small studio apartment  
  : 작은 스튜디오 아파트로 이사하다

- something simple and not too large  
  : 단순하고 너무 크지 않은 것

  : 작은 스튜디오에 잘 맞다

  : 2인용 소파

  : 잘 어울리는 커피 테이블

  : 모든 것을 옮기고 조립하다

  : 여러 제품을 함께 구매하다

- make my decision  
  : 결정을 내리다

## Notes

- 핵심 순서는 `침대 → 소파·테이블 → 배송·조립 → 할인`이다.
- 제품에 대한 긴 설명보다 질문을 분명하게 말하는 것이 중요하다.
- 질문을 잊어버리면 `가격 → 배송 → 할인` 세 가지만이라도 확실히 묻는다.
- `furniture`는 셀 수 없는 명사이므로 `furnitures`라고 하지 않는다.
- 문장 난이도를 억지로 높이지 않고, 자연스러운 질문과 반응으로 IH를 노린다.
