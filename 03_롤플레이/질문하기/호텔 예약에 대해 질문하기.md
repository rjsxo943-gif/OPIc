# 롤플레이 - 호텔 예약에 대해 질문하기

## Situation

호텔에 전화해서 예약 전에 필요한 정보를 질문하기.

---

## Speaking Order

인사 → 방 가능 여부 → 가격 → 체크인 시간 → 마무리

---

## Full Script

Hi, / I'm calling to ask / about a room reservation.

I'd like to stay / for two nights / next weekend.

Do you have / any rooms available?

If you do, / how much is a room / per night?

Also, / what time is check-in?

And is breakfast / included in the price?

Okay, / that sounds good.

Thank you for the information. / I'll check my schedule / and call you back.

---

## 직독직해

안녕하세요, / 저는 물어보려고 전화드렸어요 / 객실 예약에 대해.

저는 머물고 싶어요 / 이틀 밤 동안 / 다음 주말에.

가능한 방이 / 있나요?

있다면, / 방 가격이 얼마인가요 / 1박에?

또한, / 체크인은 몇 시인가요?

그리고 아침 식사는 / 가격에 포함되어 있나요?

좋아요, / 괜찮네요.

정보 감사합니다. / 제 일정을 확인하고 / 다시 전화드릴게요.

---

## Key Questions

- Do you have any rooms available?
- How much is a room per night?
- What time is check-in?
- Is breakfast included?
