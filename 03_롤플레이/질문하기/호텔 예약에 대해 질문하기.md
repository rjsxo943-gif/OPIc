# 롤플레이 - 호텔 예약에 대해 질문하기

## Situation

휴가를 위해 호텔을 예약하려고 한다.

호텔 직원에게 전화해서 객실 예약에 관해 세 가지 또는 네 가지 질문을 한다.

---

## Speaking Order

인사와 전화 목적

↓

원하는 날짜에 객실이 있는지 질문

↓

객실 종류와 가격 질문

↓

결제 시기와 취소 규정 질문

↓

감사 인사

---

## Full Script

Hello, / is this the Grand Hotel?

Hi, / I'm planning a trip / next month, / and I'd like to book a room. / Before I make a reservation, / I have a few questions.

First of all, / do you have any rooms available / from August 15th / to August 18th?

Oh, you do? / That's great.

I'm traveling / with a friend, / so what kind of room / would you recommend / for two people? / Also, / how much is it / per night?

I see. / A twin room / sounds good.

One more thing. / Do I need to pay / when I make the reservation, / or can I pay / when I check in?

Okay, / I can pay / when I check in. / That's convenient.

Finally, / could you tell me / about your cancellation policy? / Would I be able to cancel / the reservation / without a fee / if my plans changed?

Oh, / I understand. / That's good to know.

Thank you so much / for all the information. / You've been / very helpful.

I'll talk / to my friend / and call you back / to make the reservation.

Thanks again. / Bye!

## 직독직해

안녕하세요, / 저는 여행을 계획하고 있습니다 / 다음 달에, / 그리고 방을 예약하고 싶습니다. / 예약하기 전에, / 몇 가지 질문이 있습니다.

우선, / 가능한 방이 있나요 / 8월 15일부터 / 8월 18일까지?

아, 있나요? / 좋네요.

저는 여행합니다 / 친구 한 명과, / 그래서 어떤 종류의 방을 / 추천하시겠어요 / 두 명에게? / 또, / 가격은 얼마인가요 / 1박에?

그렇군요. / 트윈룸이 / 괜찮아 보이네요.

한 가지 더요. / 제가 결제해야 하나요 / 예약할 때, / 아니면 결제할 수 있나요 / 체크인할 때?

좋아요, / 저는 결제할 수 있군요 / 체크인할 때. / 편리하네요.

마지막으로, / 알려주실 수 있나요 / 취소 규정에 대해? / 제가 취소할 수 있을까요 / 예약을 / 수수료 없이 / 제 계획이 바뀐다면?

아, / 알겠습니다. / 알아두면 좋겠네요.

정말 감사합니다 / 모든 정보에 대해. / 정말 / 도움이 많이 됐습니다.

저는 이야기해 보고 / 제 친구와 / 다시 전화드릴게요 / 예약하기 위해.

다시 한번 감사합니다. / 안녕히 계세요!

## 핵심 질문

### 객실 이용 가능 여부

Do you have any rooms available from August 15th to August 18th?

### 객실 종류와 가격

What kind of room would you recommend for two people?

How much is it per night?

### 결제 시기

Do I need to pay when I make the reservation?

Can I pay when I check in?

### 취소 규정

Could you tell me about your cancellation policy?

Would I be able to cancel without a fee?

---

## 공통 반응 표현

- Oh, you do? That's great.
- I see.
- That sounds good.
- That's convenient.
- That's good to know.
- I understand.

---

## 재사용 가능한 호텔 질문

- Is breakfast included in the price?
- What time is check-in?
- What time do I need to check out?
- Is there free Wi-Fi in the room?
- Is the hotel close to public transportation?
- Do you offer any discounts?
- Does the hotel have a swimming pool or a fitness center?

## Notes

- 날짜는 시험에서 편한 날짜로 자유롭게 바꿔도 된다.
- 객실 질문이 어렵다면 `Do you have a room for two people?`로 단순화한다.
- 핵심은 문장 암기보다 `날짜 → 방과 가격 → 결제·취소` 순서를 기억하는 것이다.
