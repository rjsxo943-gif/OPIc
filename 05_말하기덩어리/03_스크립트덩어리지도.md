# 스크립트 덩어리 지도

> 각 기존 스크립트가 어떤 **2~4개의 큰 덩어리**로 구성되는지 한눈에 보는 지도다. 자세한 영어 본문은 각 주제별 분할 파일에서 확인한다.

---

# 자기소개

## [[01_설문스크립트/자기소개/자기소개|자기소개]]

```text
SELF-1 학생과 현재 진로
→ SELF-2 전공 관심과 SDR 프로젝트
→ SELF-3 성격과 취미
→ SELF-4 미래의 모습
```

---

# 집

## [[01_설문스크립트/집/현재집|현재 집]]

```text
현재 Full Script 미작성
권장: 스튜디오 소개 → 내부 구조 → 활동과 장점
```

## [[01_설문스크립트/집/좋아하는 공간 - 침대 주변|좋아하는 공간]]

```text
HOME-FAV-1 집 구조와 공간 선택
→ HOME-FAV-2 침대 주변 배치와 분위기
→ HOME-FAV-3 그곳에서 하는 일
→ HOME-FAV-4 나만의 안식처
```

## [[01_설문스크립트/집/과거집비교|과거와 현재 집 비교]]

```text
HOME-COMP-1 과거 집과 독립
→ HOME-COMP-2 과거 가족 집
→ HOME-COMP-3 현재 스튜디오
→ HOME-COMP-4 현재 집을 좋아하는 이유
```

## [[01_설문스크립트/집/집문제|집에서 생긴 문제]]

```text
HOME-PROBLEM-1 욕실 누수 발견
→ HOME-PROBLEM-2 배관공 호출과 대기
→ HOME-PROBLEM-3 수리와 청소
→ HOME-PROBLEM-4 혼자 사는 삶의 교훈
```

## [[01_설문스크립트/집/집변화|집에 준 변화]]

```text
HOME-CHANGE-1 새 침대와 수면 개선
→ HOME-CHANGE-2 러그와 가구 재배치
→ HOME-CHANGE-3 진짜 내 공간이 됨
```

# 집에서 보내는 휴가

## [[01_설문스크립트/집에서보내는휴가/집에서 보내는 휴가 - 평소 활동 경향|평소 활동 경향]]

```text
VAC-HABIT-1 집에서 쉬는 이유
→ VAC-HABIT-2 느긋한 아침과 콘텐츠
→ VAC-HABIT-3 독서·휴식·가족 음식
→ VAC-HABIT-4 산책과 재충전
```

## [[01_설문스크립트/집에서보내는휴가/집에서 보내는 휴가 - 기억에 남는 휴가|기억에 남는 휴가]]

```text
VAC-MEM-1 시험 후 완전한 자유
→ VAC-MEM-2 죄책감 없는 휴식
→ VAC-MEM-3 가족과 평범한 저녁
→ VAC-MEM-4 지금 더 특별한 이유
```

## [[01_설문스크립트/집에서보내는휴가/집에서 보내는 휴가 - 휴가 관련 이슈|휴가 관련 이슈]]

```text
VAC-ISSUE-1 휴가가 필요한 이유
→ VAC-ISSUE-2 활동형과 회복형 비교
→ VAC-ISSUE-3 현재 나에게 필요한 휴가
→ VAC-ISSUE-4 목적에 맞는 휴가
```

# 공원

## [[01_설문스크립트/공원/좋아하는 공원|좋아하는 공원]]

```text
PARK-FAV-1 공원 취향과 대상 소개
→ PARK-FAV-2 위치와 접근성
→ PARK-FAV-3 시설과 봄 정원
→ PARK-FAV-4 도심 속 자연
```

## [[01_설문스크립트/공원/공원에서 하는 활동|공원 활동]]

```text
PARK-HABIT-1 가까운 공원과 방문 빈도
→ PARK-HABIT-2 혼자 새벽에 가는 이유
→ PARK-HABIT-3 러닝 루틴
→ PARK-HABIT-4 건강과 자연
```

## [[01_설문스크립트/공원/공원에서 겪은 기억에 남는 경험|공원 경험]]

```text
PARK-MEM-1 가을 축제 분위기
→ PARK-MEM-2 옛 벤치와 전 여자친구
→ PARK-MEM-3 충격과 민망함
→ PARK-MEM-4 지금은 웃긴 기억
```

# 해변과 캠핑

## [[01_설문스크립트/해변과캠핑/좋아하는 해변|좋아하는 해변]]

```text
BEACH-FAV-1 부산과 광안리 소개
→ BEACH-FAV-2 위치·이동·친구
→ BEACH-FAV-3 낮의 활동과 분위기
→ BEACH-FAV-4 일몰·야경·스트레스 해소
```

## [[01_설문스크립트/해변과캠핑/해변을 가는 경향|해변 경험]]

```text
BEACH-MEM-1 힘들어하던 친구와 즉흥 출발
→ BEACH-MEM-2 좋은 날씨와 돗자리 대화
→ BEACH-MEM-3 산책·일몰·야경
→ BEACH-MEM-4 친구의 감정 변화와 의미
```

## [[01_설문스크립트/해변과캠핑/해변에 가져가는 물건|캠핑 준비물]]

```text
CAMP-ITEM-1 여행 성격과 기본 장비
→ CAMP-ITEM-2 개인 물품·요리·음식
→ CAMP-ITEM-3 기타 필수품과 준비의 가치
```

## [[01_설문스크립트/해변과캠핑/캠핑 간 경험|캠핑 경험]]

```text
CAMP-MEM-1 친구들과 송정 출발
→ CAMP-MEM-2 날씨·분위기·텐트 설치
→ CAMP-MEM-3 산책·저녁·밤
→ CAMP-MEM-4 다음 날과 여행의 의미
```

# 음악

## [[01_설문스크립트/음악/좋아하는 가수 (Standard Script)|좋아하는 가수]]

```text
MUSIC-FAV-1 빈지노 소개
→ MUSIC-FAV-2 음악 스타일
→ MUSIC-FAV-3 24:26과 Aqua Man
→ MUSIC-FAV-4 언제 듣는지와 의미
```

## [[01_설문스크립트/음악/음악 감상 활동 경향|음악 활동 경향]]

```text
MUSIC-HABIT-1 활동에 따라 음악 선택
→ MUSIC-HABIT-2 운동에는 랩
→ MUSIC-HABIT-3 공부·독서에는 클래식
→ MUSIC-HABIT-4 기기·앱과 음악의 의미
```

## [[01_설문스크립트/음악/음악 감상 취향의 변화|음악 취향 변화]]

```text
MUSIC-CHANGE-1 과거 한국 힙합 중심
→ MUSIC-CHANGE-2 가사가 공부를 방해
→ MUSIC-CHANGE-3 클래식 발견
→ MUSIC-CHANGE-4 현재는 상황별 선택
```

## [[01_설문스크립트/음악/음악 감상 도중 겪은 기억에 남는 경험|음악 경험]]

```text
MUSIC-MEM-1 빈지노가 온 축제
→ MUSIC-MEM-2 공연 전과 등장
→ MUSIC-MEM-3 Aqua Man 라이브
→ MUSIC-MEM-4 친구들과 공유한 의미
```
