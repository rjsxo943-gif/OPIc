# 큰 덩어리 변형 조합 연습

> 목표는 스크립트를 잘게 해체하는 것이 아니다. **큰 덩어리를 통째로 외운 뒤**, 같은 역할을 하는 다른 덩어리들과 비교하면서 선택 폭을 넓히는 것이다.

---

# 1. 먼저 원래 스크립트대로 외운다

예시: 광안리 경험

```text
BEACH-MEM-1 힘들어하던 친구와 즉흥 출발
→ BEACH-MEM-2 좋은 날씨와 돗자리 대화
→ BEACH-MEM-3 산책·일몰·야경
→ BEACH-MEM-4 친구의 감정 변화와 의미
```

처음에는 이 네 덩어리를 원래 순서대로 충분히 익힌다.

각 덩어리의 영어 문장을 통째로 읽고, 나중에는 아래 장면만 보고 복원한다.

```text
친구 스트레스
→ 즉흥 광안리
→ 맑은 하늘과 돗자리
→ 산책과 광안대교
→ 친구가 편안해짐
```

---

# 2. 덩어리 하나를 장면으로 기억한다

문장 하나하나를 따로 기억하지 않는다.

예시: `TRAVEL-MEM-2`

```text
게르 밖
+ 의자 위 간식과 보드카
+ 친구들과 땅에 앉음
+ 불빛 없는 밤하늘
+ 셀 수 없는 별
```

이 장면 전체가 한 덩어리다.

영어 표현 일부가 달라져도 이 장면을 끝까지 설명할 수 있으면 성공이다.

---

# 3. 비슷한 덩어리를 나란히 연습한다

## 함께 출발한 배경

```text
BEACH-MEM-1
친구 한 명이 스트레스 → 즉흥적으로 광안리

CAMP-MEM-1
친구들 모두 바쁨 → 주말 송정 캠핑

MUSIC-MEM-1
빈지노가 학교 축제에 옴 → 좋아하는 친구들과 공연

TRAVEL-MEM-1
대학 친구 두 명 → 몽골 여행 중 게르 숙박
```

이 네 덩어리를 연달아 말하면 경험 답변의 도입을 여러 방식으로 시작할 수 있다.

## 앉아서 먹고 대화한 장면

```text
BEACH-MEM-2
돗자리 + 편의점 간식 + 음악 + 인생 이야기

CAMP-MEM-3
그릴 음식 + 일몰 + 텐트 밖 음악 + 긴 대화

TRAVEL-MEM-2~3
건망고와 보드카 + 별 + 음식·연애 이야기 + 큰 개들

VAC-MEM-3
가족 + 치킨과 피자 + 평범한 이야기
```

## 평범하지만 의미 있었던 마무리

```text
BEACH-MEM-4
친구가 편안해짐

CAMP-MEM-4
짧았지만 스트레스를 잊음

TRAVEL-MEM-4
관광지가 아닌 별밤이 가장 특별함

MUSIC-MEM-4
익숙한 노래를 친구들과 공유함

VAC-MEM-4
현재의 압박 때문에 그 휴식이 더 특별함
```

---

# 4. 조합은 문맥이 맞는 범위에서만 바꾼다

모든 덩어리를 아무렇게나 섞지 않는다.

좋은 변형:

```text
BEACH-MEM-1
→ BEACH-MEM-2
→ BEACH-FAV-4
→ BEACH-MEM-4
```

해변 경험에서 원래의 산책 장면 대신, 좋아하는 해변 스크립트의 광안대교 묘사를 조금 더 풍부하게 가져온 형태다.

좋은 변형:

```text
CAMP-MEM-1
→ CAMP-MEM-2
→ BEACH-FAV-3
→ CAMP-MEM-3
→ CAMP-MEM-4
```

캠핑 중 해변 산책을 말할 때 좋아하는 해변의 파도와 분위기 묘사를 응용한다.

나쁜 변형:

```text
PARK-MEM-2 전 여자친구 발견
→ TRAVEL-MEM-3 몽골의 큰 개들
```

같은 경험 안에서 연결될 이유가 없으므로 사용하지 않는다.

---

# 5. 원본 유지형·부분 교체형·즉석 선택형

## 1단계 — 원본 유지형

스크립트의 모든 덩어리를 원래 순서대로 말한다.

```text
A → B → C → D
```

이 단계에서는 외우는 맛과 전체 흐름을 만든다.

## 2단계 — 부분 교체형

원래 덩어리 하나를 비슷한 역할의 덩어리 표현으로 보강하거나 교체한다.

```text
A → B' → C → D
```

예시:

- 광안리 경험의 풍경을 `BEACH-FAV-4`로 보강
- 캠핑의 대화 장면을 `BEACH-MEM-2`의 표현 방식으로 말함
- 몽골 경험의 의미를 `BEACH-MEM-4`와 비슷한 구조로 정리

## 3단계 — 즉석 선택형

질문을 듣고 같은 계열의 여러 덩어리 중 먼저 떠오르는 것을 선택한다.

```text
경험 배경 1개
+ 주요 활동 1~2개
+ 인상적인 장면 1개
+ 의미 1개
```

---

# 6. 질문 유형별 큰 그림

## 장소 설명

```text
대상 선택
→ 위치와 기본 모습
→ 가장 좋아하는 풍경·시설
→ 나에게 주는 의미
```

사용 가능한 덩어리:

- 공원: `PARK-FAV-1~4`
- 해변: `BEACH-FAV-1~4`
- 집: `HOME-FAV-1~4`
- 여행지: `TRAVEL-FAV-1~4`

## 활동 경향

```text
평소 성향
→ 언제·누구와 하는지
→ 구체적인 루틴
→ 좋아하는 이유
```

사용 가능한 덩어리:

- 공원: `PARK-HABIT-1~4`
- 음악: `MUSIC-HABIT-1~4`
- 집 휴가: `VAC-HABIT-1~4`
- 여행 준비: `TRAVEL-PREP-1~4`

## 경험

```text
언제·누구와·왜
→ 현장의 활동
→ 가장 인상적인 사건이나 장면
→ 감정 변화와 의미
```

사용 가능한 덩어리:

- 공원: `PARK-MEM-1~4`
- 해변: `BEACH-MEM-1~4`
- 캠핑: `CAMP-MEM-1~4`
- 음악: `MUSIC-MEM-1~4`
- 여행: `TRAVEL-MEM-1~4`
- 집 휴가: `VAC-MEM-1~4`
- 집 문제: `HOME-PROBLEM-1~4`

## 비교·변화

```text
과거 상태
→ 차이 또는 불편함
→ 변화 계기
→ 현재 상태와 평가
```

사용 가능한 덩어리:

- 집 비교: `HOME-COMP-1~4`
- 음악 변화: `MUSIC-CHANGE-1~4`
- 휴가 이슈: `VAC-ISSUE-1~4`
- 집 변화: `HOME-CHANGE-1~3`

---

# 7. 하루 연습 방식

## 1회차 — 한 스크립트 통째로

- 덩어리 제목과 장면을 확인한다.
- 영어 본문을 보며 처음부터 끝까지 말한다.
- 원래 순서를 유지한다.

## 2회차 — 덩어리별 복원

- 영어 본문을 가린다.
- 한국어 장면만 보고 각 덩어리를 말한다.
- 덩어리 사이에서 잠깐 쉬어도 된다.

## 3회차 — 유사 덩어리 비교

- 오늘 스크립트와 비슷한 역할의 덩어리를 2개 고른다.
- 차이점을 의식하면서 연달아 말한다.

예시:

```text
BEACH-MEM-4 → CAMP-MEM-4 → TRAVEL-MEM-4
```

## 4회차 — 한 부분만 변형

- 원래 답변에서 덩어리 하나만 표현을 바꾼다.
- 나머지 덩어리는 원본대로 유지한다.
- 처음부터 모든 순서를 섞지 않는다.

---

# 8. 암기 체크 기준

## 덩어리 암기 완료

- [ ] 덩어리의 장면을 한국어로 바로 설명할 수 있다.
- [ ] 영어로 20~40초 정도 끊기지 않고 말할 수 있다.
- [ ] 첫 문장을 들으면 나머지 장면이 이어서 떠오른다.
- [ ] 문장 하나를 잊어도 덩어리 전체가 무너지지 않는다.

## 스크립트 암기 완료

- [ ] 2~4개 덩어리의 순서를 그림처럼 떠올릴 수 있다.
- [ ] 원본 순서로 한 번 끝까지 말할 수 있다.
- [ ] 덩어리 하나를 생략해도 자연스럽게 마무리할 수 있다.
- [ ] 비슷한 덩어리의 다른 표현을 일부 가져올 수 있다.
