# 기존 스크립트 요소 조합표

> 현재 저장소의 설문 스크립트가 어떤 말하기 요소의 조합으로 만들어졌는지 정리한 표다. 요소의 영어 본문은 [[05_말하기요소/01_공통요소|공통 요소]]와 [[05_말하기요소/02_주제전용요소|주제 전용 요소]]에서 확인한다.

---

## 표 읽는 방법

```text
A → B → C → D
```

원래 Full Script가 대체로 A, B, C, D의 순서로 구성되어 있다는 뜻이다.

- **필수**: 질문에 직접 답하기 위해 남기는 요소
- **선택**: 시간이 부족하거나 잘 생각나지 않으면 빼도 되는 요소
- 시험에서는 원래 순서를 완벽하게 복원하지 않아도 된다.
- 주제 전용 요소 한 개 이상과 마무리 요소 하나만 확보해도 답변이 성립한다.

---

# 자기소개

## [[01_설문스크립트/자기소개/자기소개|자기소개]]

**원래 조합**

```text
SELF-01
→ SELF-02
→ SELF-03
→ SELF-04
```

- 필수: `SELF-01`, `SELF-03`
- 선택: `SELF-02`
- 마무리: `SELF-04`
- 인사와 긴장된다는 문장은 고정 요소가 아니라 자연스러운 워밍업 문장으로 사용한다.

# 집

## [[01_설문스크립트/집/현재집|현재 집]]

**현재 상태:** Full Script가 아직 작성되지 않은 빈 템플릿이다.

**권장 조합**

```text
HOME-01
→ HOME-02
→ PLACE-SMALLCOZY-01
→ HOME-03
→ END-SAFEHAVEN-01
```

## [[01_설문스크립트/집/좋아하는 공간 - 침대 주변|좋아하는 공간 - 침대 주변]]

**원래 조합**

```text
HOME-01
→ HOME-02
→ PLACE-SMALLCOZY-01
→ HOME-03
→ END-SAFEHAVEN-01
```

- 필수: `HOME-01`, `HOME-02`, `END-SAFEHAVEN-01`
- 선택: `PLACE-SMALLCOZY-01`, `HOME-03`의 세부 활동

## [[01_설문스크립트/집/과거집비교|과거 집과 현재 집 비교]]

**원래 조합**

```text
INTRO-COMP-01
→ HOME-04
→ HOME-01
→ PLACE-SMALLCOZY-01
→ HOME-03
→ END-SAFEHAVEN-01
```

- 필수: `HOME-04`와 `HOME-01`의 대비
- 선택: 가족 집의 방 개수, 현재 집의 가전제품 목록
- `HOME-03`은 현재 집이 좋은 이유를 설명하는 근거로 사용한다.

## [[01_설문스크립트/집/집문제|집에서 생긴 문제]]

**원래 조합**

```text
INTRO-EXP-01
→ HOME-06
→ EXP-PROBLEM-01
→ EXP-SOLUTION-01
→ END-MEANING-01
```

- 필수 사건: `HOME-06`
- 필수 전개: `EXP-PROBLEM-01 → EXP-SOLUTION-01`
- 마지막에는 혼자 살면 예상 밖 문제를 직접 처리해야 한다는 교훈을 덧붙인다.

## [[01_설문스크립트/집/집변화|집에 준 변화]]

**원래 조합**

```text
INTRO-CHANGE-01
→ HOME-05
→ COMP-CHANGE-01
→ END-SAFEHAVEN-01
```

- 필수: 새 침대와 가구 재배치
- 선택: 러그 또는 커피·유튜브·독서 중 하나
- 변화 하나를 말한 뒤 반드시 결과를 붙인다.

# 집에서 보내는 휴가

## [[01_설문스크립트/집에서보내는휴가/집에서 보내는 휴가 - 평소 활동 경향|평소 활동 경향]]

**원래 조합**

```text
INTRO-HABIT-01
→ PEOPLE-ALONE-01
→ VAC-01
→ VAC-02
→ PEOPLE-FAMILY-01
→ ACT-WALK-01
→ END-RELAX-01
```

- 필수: `VAC-01`, `VAC-02`, `END-RELAX-01`
- 선택: 가족과 음식, 산책 또는 카페 독서
- 혼자 있는 낮과 가족과 있는 저녁을 모두 넣으면 긴 답변이 된다.

## [[01_설문스크립트/집에서보내는휴가/집에서 보내는 휴가 - 기억에 남는 휴가|기억에 남는 휴가]]

**원래 조합**

```text
INTRO-EXP-01
→ VAC-03
→ ACT-REST-01
→ VAC-04
→ EXP-SIMPLE-MEANING-01
→ END-MEANING-01
→ END-AGAIN-01
```

- 필수: 시험 종료 후 아무 일정도 없었던 감정
- 선택: 곽튜브의 유럽 신혼여행 영상
- 현재 취업 준비와 비교하는 문단은 길이를 늘릴 때만 사용한다.

## [[01_설문스크립트/집에서보내는휴가/집에서 보내는 휴가 - 휴가 관련 이슈|휴가 관련 이슈]]

**원래 조합**

```text
INTRO-ISSUE-01
→ VAC-05
→ COMP-TWOSIDES-01
→ COMP-PERSONAL-NOW-01
→ COMP-PURPOSE-01
```

- 필수: 활동적인 휴가와 회복형 휴가의 비교
- 내 상황: 부트캠프·공부·취업 준비 때문에 지금은 회복이 더 필요함
- 결론: 좋은 휴가는 자신의 목적에 맞는 휴가

# 공원

## [[01_설문스크립트/공원/좋아하는 공원|좋아하는 공원]]

**원래 조합**

```text
INTRO-FAV-01
→ PARK-01
→ PARK-02
→ PLACE-NATURE-01
→ END-FAVORITE-01
```

- 필수: `PARK-01`, `PARK-02`
- 선택: 축구장과 농구장 목록
- 핵심 이미지: 봄에 피는 꽃과 향기

## [[01_설문스크립트/공원/공원에서 하는 활동|공원에서 하는 활동]]

**원래 조합**

```text
INTRO-HABIT-01
→ PARK-01
→ PEOPLE-ALONE-01
→ PARK-03
→ END-RELAX-01
```

- 필수: 새벽에 혼자 가는 이유와 러닝 루틴
- 선택: 봄에는 친구나 가족과 산책한다는 내용
- `PARK-03`의 운동기구와 에너지 음료는 시간이 부족하면 뺀다.

## [[01_설문스크립트/공원/공원에서 겪은 기억에 남는 경험|공원에서 겪은 기억에 남는 경험]]

**원래 조합**

```text
INTRO-EXP-01
→ PLACE-ATM-01
→ PARK-04
→ EXP-EMOTION-01
→ EXP-LOOKBACK-01
```

- 선택 배경: 음식 트럭, 작은 부스, 라이브 음악
- 필수 사건: 예전 벤치에서 전 여자친구와 다른 남자를 발견함
- 필수 마무리: 당시에는 불편했지만 지금은 웃긴 기억

# 해변과 캠핑

## [[01_설문스크립트/해변과캠핑/좋아하는 해변|좋아하는 해변]]

**원래 조합**

```text
INTRO-FAV-01
→ BEACH-01
→ BEACH-02
→ PLACE-DAYNIGHT-01
→ BEACH-03
→ END-RELAX-01
```

- 필수: 광안리 위치와 광안대교 야경
- 선택: 돗자리 또는 긴 산책 중 하나
- 낮의 활기와 저녁의 평화를 비교하면 묘사가 풍부해진다.

## [[01_설문스크립트/해변과캠핑/해변을 가는 경향|해변을 가는 경향]]

**원래 조합**

```text
INTRO-EXP-01
→ PEOPLE-FRIENDS-01
→ PLACE-NATURE-01
→ BEACH-02
→ BEACH-03
→ END-MEANING-01
→ END-RELAX-01
```

- 필수: 스트레스받은 친구와 즉흥적으로 광안리에 감
- 선택: 편의점 간식, 사진 촬영, 벤치에서 긴 대화
- 감정 흐름: stressed → relaxed → meaningful

## [[01_설문스크립트/해변과캠핑/해변에 가져가는 물건|해변에 가져가는 물건]]

**원래 조합**

```text
PEOPLE-FRIENDS-01
→ CAMP-01
→ CAMP-02
→ END-FAVORITE-01
```

- `CAMP-01`: 기본 장비와 요리 장비
- `CAMP-02`: 개인 물품, 음식, 기타 필수품
- 물건을 하나씩 외우지 말고 `잠자리 → 개인 물품 → 요리 → 음식 → 기타`의 카테고리 순서로 기억한다.

## [[01_설문스크립트/해변과캠핑/캠핑 간 경험|캠핑 간 경험]]

**원래 조합**

```text
INTRO-EXP-01
→ PEOPLE-FRIENDS-01
→ CAMP-03
→ PLACE-NATURE-01
→ CAMP-04
→ END-MEANING-01
→ END-AGAIN-01
```

- 필수: 송정, 친구 3명, 텐트 설치, 저녁 활동
- 선택: 다음 날 아침 식사와 마지막 산책
- 핵심 흐름: 설치 → 해변 → 저녁 → 밤 → 회고

# 음악

## [[01_설문스크립트/음악/좋아하는 가수 (Standard Script)|좋아하는 가수]]

**원래 조합**

```text
INTRO-FAV-01
→ MUSIC-01
→ MUSIC-02
→ MUSIC-03
→ END-IDENTITY-01
```

- 필수: 빈지노 소개와 좋아하는 이유
- 선택 A: `MUSIC-02`의 Aqua Man 입문 이야기
- 선택 B: 빠른 노래와 느린 노래의 분위기 비교
- 마무리 이미지: 내 청춘의 사운드트랙

## [[01_설문스크립트/음악/음악 감상 활동 경향|음악 감상 활동 경향]]

**원래 조합**

```text
INTRO-HABIT-01
→ MUSIC-03
→ MUSIC-04
→ END-IDENTITY-01
```

- 필수: 운동에는 랩, 공부·독서에는 클래식
- 선택: 산책할 때 음악을 듣는 내용
- 기기·앱은 `AirPods → Melon → YouTube` 중 두 개만 말해도 충분하다.

## [[01_설문스크립트/음악/음악 감상 취향의 변화|음악 감상 취향의 변화]]

**원래 조합**

```text
INTRO-COMP-01
→ MUSIC-01
→ COMP-DISCOVERY-01
→ MUSIC-03
→ END-IDENTITY-01
```

- 과거: 한국 힙합만 주로 들음
- 계기: 가사가 시험공부를 방해함
- 현재: 활동에 따라 랩과 클래식을 선택함
- 변화 답변이므로 가수 목록보다 변화의 계기가 중요하다.

## [[01_설문스크립트/음악/음악 감상 도중 겪은 기억에 남는 경험|음악 감상 경험]]

**원래 조합**

```text
INTRO-EXP-01
→ PEOPLE-FRIENDS-01
→ MUSIC-05
→ MUSIC-06
→ PEOPLE-SHARE-01
→ END-AGAIN-01
```

- 필수: 대학교 축제, 빈지노, Aqua Man 라이브
- 선택: 휴대전화로 짧은 영상을 찍은 내용
- 다른 음악 답변의 `MUSIC-01`, `MUSIC-02`를 그대로 재사용할 수 있다.

# 해외여행

## [[01_설문스크립트/해외여행/가장 좋아하는 해외 여행지|가장 좋아하는 해외 여행지]]

**원래 조합**

```text
INTRO-FAV-01
→ TRAVEL-01
→ TRAVEL-02
→ TRAVEL-03
→ ACT-FOOD-01
→ END-RECOMMEND-01
```

- 필수: 몽골 선택 이유와 자연환경
- 선택: 비가 내린 사막과 꽃을 먹은 경험
- 음식과 보드카는 짧은 추가 이유로만 사용한다.

## [[01_설문스크립트/해외여행/가장 기억에 남는 여행 경험|가장 기억에 남는 여행 경험]]

**원래 조합**

```text
INTRO-EXP-01
→ TRAVEL-01
→ TRAVEL-04
→ TRAVEL-05
→ TRAVEL-06
→ EXP-SIMPLE-MEANING-01
→ END-MEANING-01
```

- 필수 장면: 게르 밖에서 친구들과 별을 보며 보드카를 마신 밤
- 선택: 보드카 브랜드 비교 또는 큰 개들 중 하나
- 핵심 의미: 관광지가 아니라 사람과 분위기가 평범한 밤을 특별하게 만듦

## [[01_설문스크립트/해외여행/여행 전 준비하는 활동 경향|여행 전 준비하는 활동 경향]]

**원래 조합**

```text
INTRO-HABIT-01
→ TRAVEL-07
→ ACT-FOOD-01
→ TRAVEL-08
→ TRAVEL-09
```

- 필수: 빡빡하게 계획하지 않는 여행 스타일
- 선택: 구글 지도와 택시 이야기
- 준비물은 물건 목록보다 `pack light`라는 성향을 중심으로 말한다.
- `TRAVEL-09`가 감정적인 마무리 역할을 한다.

# 한눈에 보는 재사용 관계

|요소|함께 쓰이는 스크립트|
|---|---|
|`PARK-01`|좋아하는 공원, 공원 활동|
|`BEACH-02`|좋아하는 해변, 해변 경험|
|`BEACH-03`|좋아하는 해변, 해변 경험|
|`HOME-01`|현재 집, 좋아하는 공간, 집 비교|
|`HOME-03`|좋아하는 공간, 집 비교, 집에서 쉬는 답변|
|`MUSIC-01`|좋아하는 가수, 취향 변화, 음악 경험|
|`MUSIC-02`|좋아하는 가수, 음악 경험|
|`MUSIC-03`|좋아하는 가수, 활동 경향, 취향 변화|
|`TRAVEL-01`|좋아하는 여행지, 기억에 남는 여행|

|`END-RELAX-01`|공원 활동, 해변, 집에서 보내는 휴가|
|`END-MEANING-01`|해변 경험, 캠핑, 집에서 보낸 휴가, 여행 경험|
