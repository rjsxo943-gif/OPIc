# 말하기 요소 조합 연습

> 목표는 Full Script의 문장 순서를 복원하는 것이 아니라, 질문을 듣고 먼저 떠오르는 요소를 골라 자연스럽게 연결하는 것이다.

---

# 1. 요소 하나 복원하기

영어 문장을 보지 않고 키워드만 본다.

예시:

```text
BEACH-03
일몰 → 어두워짐 → 광안대교 조명
```

키워드를 보고 10~20초 동안 말한다.

```text
The sunset is beautiful, but the night view is even more impressive.
As it gets darker, Gwangandaegyo Bridge lights up and shines over the water.
```

완벽히 같은 문장이 나오지 않아도 된다. 핵심 의미가 유지되면 성공이다.

---

# 2. 두 요소 연결하기

서로 자연스럽게 이어지는 요소 두 개를 선택한다.

```text
BEACH-02 → BEACH-03
```

연결어를 하나만 넣어 말한다.

```text
Later, ...
As it got darker, ...
Another thing I like is ...
```

## 추천 조합

- `PARK-01 → PARK-02`
- `HOME-02 → HOME-03`
- `MUSIC-01 → MUSIC-02`
- `MUSIC-03 → MUSIC-04`
- `TRAVEL-04 → TRAVEL-05`
- `CAMP-03 → CAMP-04`
- `VAC-01 → VAC-02`
- `EXP-PROBLEM-01 → EXP-SOLUTION-01`

---

# 3. 같은 질문에 다른 조합 사용하기

## 광안리 경험 질문

### 조합 A — 풍경 중심

```text
INTRO-EXP-01
→ PEOPLE-FRIENDS-01
→ PLACE-NATURE-01
→ BEACH-03
→ END-MEANING-01
```

### 조합 B — 활동 중심

```text
INTRO-EXP-01
→ PEOPLE-FRIENDS-01
→ BEACH-02
→ ACT-SIT-TALK-01
→ END-RELAX-01
```

### 조합 C — 짧은 답변

```text
INTRO-EXP-01
→ BEACH-02
→ BEACH-03
→ END-MEANING-01
```

같은 경험이라도 먼저 생각나는 내용에 따라 답변이 달라진다.

---

# 4. 길이별 조합

## 60초 답변

```text
도입 1
+ 주제 전용 요소 2
+ 마무리 1
```

예시:

```text
INTRO-FAV-01
→ PARK-01
→ PARK-02
→ END-FAVORITE-01
```

## 90초 답변

```text
도입 1
+ 주제 전용 요소 2~3
+ 공통 요소 1
+ 마무리 1
```

예시:

```text
INTRO-FAV-01
→ BEACH-01
→ BEACH-02
→ PLACE-DAYNIGHT-01
→ BEACH-03
→ END-RELAX-01
```

## 120초 경험 답변

```text
도입 1
+ 배경 1
+ 사건·활동 3~4
+ 감정·의미 1
+ 마무리 1
```

예시:

```text
INTRO-EXP-01
→ TRAVEL-01
→ TRAVEL-04
→ TRAVEL-05
→ TRAVEL-06
→ EXP-SIMPLE-MEANING-01
→ END-MEANING-01
```

# 6. 생각이 끊겼을 때 복구하기

요소의 문장이 기억나지 않으면 아래 순서로 복구한다.

1. 지금 말하던 요소를 짧게 끝낸다.
2. 연결 문장 하나를 사용한다.
3. 기억나는 다른 요소로 넘어간다.

## 복구 문장

- `Another thing I remember is ...`
- `What I liked most was ...`
- `Speaking of that, ...`
- `Later, we decided to ...`
- `The best part was ...`
- `Looking back, ...`
- `Overall, ...`

## 예시

`BEACH-02`가 기억나지 않는 상황:

```text
We spent some time near the water and had a good time.
The best part was the night view.
As it got darker, Gwangandaegyo Bridge lit up...
```

정확한 원래 문장을 찾으려고 멈추지 않고 `BEACH-03`으로 넘어간다.

# 7. 하루 20분 연습

## 5분 — 요소 복원

- 공통 요소 2개
- 주제 전용 요소 2개
- 키워드만 보고 각각 한 번 말하기

## 5분 — 두 요소 연결

- 오늘의 주제에서 요소 두 개를 골라 순서를 바꾸며 말하기

## 5분 — 질문 대응

- 실제 질문 하나를 읽고 요소 4~6개를 즉석에서 선택하기
- 선택한 ID만 메모한 뒤 답변하기

## 5분 — 녹음과 수정

- 막힌 요소 하나 표시
- 필요 없는 요소 하나 삭제
- 다음 연습에서 사용할 대체 요소 하나 선택

---

# 8. 체크리스트

- [ ] 문장 전체가 아니라 키워드로 요소를 복원했다.
- [ ] 같은 질문에 두 가지 조합으로 답했다.
- [ ] 원래 스크립트와 다른 순서로도 말해 봤다.
- [ ] 주제 전용 요소를 최소 하나 사용했다.
- [ ] 생각나지 않는 요소를 건너뛰었다.
- [ ] 60초, 90초, 120초 버전을 각각 만들어 봤다.
- [ ] 녹음 후 자주 쓰는 요소와 막히는 요소를 구분했다.
