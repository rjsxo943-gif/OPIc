# Roleplay Scenario Pack D — 영화표/티켓/교통

## 유형 6 — 티켓 문의 공통형

Hello, / I have some questions / about the tickets.

First, / what time / does it start?

Also, / how much / is one ticket?

One more thing. / Can I change / the date or time / after I buy it?

Finally, / can I get a refund / if my plans change?

Okay, / that's good to know. / Thank you / for your help.

## 유형 7 — 영화표 날짜 실수

Excuse me. / there's a problem / with my movie tickets.

I accidentally bought / two tickets / for tonight, / but I need them / for tomorrow night.

Would it be possible / to change them / to tomorrow's show?

Any evening show tomorrow would be fine.

If I can't change them directly, / could I choose / a different showtime?

If that still isn't possible, / could you tell me / what other options I have?

I'm sorry / about the mistake.

Could you please check the tickets / and tell me / what I can do?
