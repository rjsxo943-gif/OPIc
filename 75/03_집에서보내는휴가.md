# 1. 평소 활동 경향

## 질문

- What do you usually do when you spend a vacation at home?
- How do you usually spend your days off at home?

## Script

I actually enjoy / spending some of my vacations at home, / especially when I'm physically / or mentally tired.

On a typical day off, / I wake up at around ten in the morning, / drink a big glass of water, / wash my face, / and have a simple breakfast.

After that, / I usually lie on my bed / and watch YouTube / or read webtoons. / I especially like travel channels / such as Pani Bottle and KwakTube / because I can see different countries / without leaving my room.

If I have a book / I'm interested in, / I read for a while too. / I don't force myself / to exercise or be productive / because the whole point / is to rest.

Sometimes, / if I stay inside for too long, / I go for a short walk / or visit a nearby café.

For me, / a stay-at-home vacation is cheap, / comfortable, / and one of the best ways / to recharge.

## 뜻

나는 꽤 좋아해 / 집에서 휴가를 보내는 것도, / 특히 몸이나 마음이 / 피곤할 때는 더 그래.

보통 쉬는 날에는, / 오전 10시쯤 일어나서, / 큰 컵으로 물을 마시고, / 세수한 뒤, / 간단하게 아침을 먹어.

그다음에는, / 주로 침대에 누워 / 유튜브를 보거나 / 웹툰을 읽어. / 특히 여행 채널을 좋아해 / 빠니보틀이나 곽튜브 같은 / 여러 나라를 볼 수 있기 때문이야 / 방을 나가지 않아도.

관심 있는 책이 있으면, / 책도 조금 읽어. / 쉬는 날에는 억지로 하지 않아 / 운동이나 생산적인 일을 / 왜냐하면 가장 중요한 건 / 쉬는 거니까.

가끔, / 집에 너무 오래 있어서 답답하면, / 짧게 산책하거나 / 근처 카페에 가기도 해.

나에게는, / 집에서 보내는 휴가가 돈도 적게 들고, / 편안하고, / 재충전하기에 가장 좋은 방법 중 / 하나야.

# 2. 기억에 남는 집에서의 휴가

## 질문

- Tell me about a memorable vacation you spent at home.
- What was your most memorable stay-at-home vacation?

## Script

The most memorable stay-at-home vacation / I can remember / was the Monday / after my final exams ended.

I had just finished / a stressful semester / and gone back to my parents' home. / I had no classes, / deadlines, / or plans, / so for the first time in a long while, / I felt completely free.

I woke up late / and spent most of the day / lying around. / I watched YouTube / and caught up on webtoons / that I had saved. / I remember watching / a KwakTube honeymoon video / about Europe, / and I started imagining / traveling there / for my own honeymoon someday.

Later, / my family came home from work. / We ordered chicken and pizza, / ate together, / and talked about ordinary things.

Nothing exciting happened that day, / but that was exactly why / it felt special. / I had nothing to worry about / and could simply enjoy / resting with my family.

## 뜻

내가 기억하는 / 가장 인상적인 집에서의 휴가는 / 기말고사가 끝난 다음 / 월요일이었어.

스트레스가 많았던 학기를 / 막 끝내고 / 부모님 집으로 돌아간 상태였어. / 수업도 없고, / 마감도 없고, / 계획도 없어서, / 정말 오랜만에 / 완전히 자유로운 기분이 들었어.

늦게 일어나서 / 하루 대부분을 / 빈둥거리며 보냈어. / 유튜브를 보고 / 미뤄두었던 웹툰도 / 몰아서 봤어. / 특히 기억나는 건 / 곽튜브의 신혼여행 영상이었는데 / 유럽에 관한 영상이었어. / 그걸 보면서 상상했어 / 나도 언젠가 그곳으로 / 신혼여행을 가는 걸.

저녁에는, / 가족들이 퇴근해서 집에 왔고, / 치킨과 피자를 시켜, / 같이 먹으면서, / 평범한 이야기를 나눴어.

그날 특별히 대단한 일은 없었지만, / 오히려 그래서 / 더 특별했어. / 걱정할 게 아무것도 없었고 / 그냥 편하게 즐길 수 있었거든 / 가족과 쉬는 시간을.

# 3. 휴가에 대한 생각

## 질문

- How do people spend their vacations these days?
- What do you think makes a good vacation?

## Script

I think people need vacations / because everyday life / can be exhausting. / Most people spend a lot of time / working, studying, / or dealing with responsibilities, / so they need time / to recover.

Some people prefer / active vacations. / They travel, / meet friends, / try new food, / and visit new places / because they want to make / special memories.

Other people would rather / stay at home, / sleep late, / watch videos, / order good food, / and simply enjoy / some time alone. / I think that kind of vacation / is also valuable, / especially when someone / is really tired.

Personally, / I enjoy both. / If I want new experiences, / I like traveling. / But these days, / because I'm busy studying / and preparing for my career, / I often prefer / a quiet day at home.

So I don't think / there is one perfect type of vacation. / A good vacation is simply one / that gives you what you need / and helps you return / to daily life / feeling refreshed.

## 뜻

나는 사람들이 휴가를 필요로 한다고 생각해 / 일상이 / 지칠 수 있기 때문이야. / 대부분의 사람들은 많은 시간을 보내 / 일하거나 공부하고, / 여러 책임을 처리하면서, / 그래서 시간이 필요해 / 회복할 수 있는.

어떤 사람들은 좋아해 / 활동적인 휴가를. / 여행을 가고, / 친구를 만나고, / 새로운 음식을 먹고, / 새로운 장소를 방문하지 / 특별한 추억을 만들고 싶어서.

반대로 어떤 사람들은 더 좋아해 / 집에 머무는 걸, / 늦잠을 자고, / 영상을 보고, / 맛있는 음식을 주문해 먹고, / 그냥 즐기는 거야 / 혼자만의 시간을. / 그런 휴가도 충분히 가치 있다고 생각해 / 특히 누군가가 / 정말 피곤할 때는.

나는 개인적으로 / 둘 다 좋아해. / 새로운 경험을 원할 때는 / 여행을 좋아해. / 하지만 요즘은, / 공부와 진로 준비로 / 바쁘기 때문에, / 자주 더 선호해 / 조용히 집에서 쉬는 날을.

그래서 나는 생각하지 않아 / 완벽한 휴가 방식이 하나만 있다고. / 좋은 휴가는 그냥 그런 거야 / 그때 나에게 필요한 것을 주고 / 다시 돌아갈 수 있게 해 주는 / 일상으로 / 상쾌한 기분으로.
