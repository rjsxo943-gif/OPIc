# 공원 — 75초 버전

> 목표: 각 답변 약 65~85초

---

# 1. 좋아하는 공원

## 질문

- Tell me about your favorite park.
- Describe a park you often visit.

## Script

My favorite park / is North Port Waterfront Park / in Busan. / It's located right behind Busan Station, / and fortunately, / it's only about a fifteen-minute walk / from my home.

I go there / at least once or twice a week, / and I visit even more often / during the spring. / The park has / nice walking trails, / plenty of benches, / and some outdoor sports facilities.

My favorite part / is the garden area. / In spring, / a lot of flowers start to bloom, / and the whole place smells / fresh and pleasant. / Even though the park is / in the middle of a big city, / it sometimes feels like / I'm somewhere in the countryside.

I usually go there / to exercise, / take a walk, / or simply clear my head.

The park can get crowded / on weekends, / but I still really enjoy it / because it's close to home / and gives me an easy way / to spend time in nature.

## 뜻

내가 가장 좋아하는 공원은 / 북항친수공원이야 / 부산에 있는. / 부산역 바로 뒤에 있고, / 다행히, / 우리 집에서 걸어서 약 15분 정도밖에 / 걸리지 않아.

나는 거기에 가 / 적어도 일주일에 한두 번은, / 그리고 봄에는 / 더 자주 방문해. / 공원에는 / 좋은 산책로와, / 많은 벤치, / 그리고 야외 운동 시설도 있어.

내가 가장 좋아하는 곳은 / 정원 구역이야. / 봄이 되면, / 꽃이 많이 피기 시작해서, / 공원 전체가 / 신선하고 좋은 향기로 가득해. / 큰 도시 / 한가운데 있는 공원인데도, / 가끔은 느껴져 / 시골에 나온 것처럼.

보통 거기에 가 / 운동을 하거나, / 산책을 하거나, / 그냥 머리를 식히기 위해서.

주말에는 사람이 많을 때도 있지만, / 그래도 정말 좋아해 / 집에서 가깝고 / 쉽게 즐길 수 있게 해 주기 때문이야 / 자연에서 보내는 시간을.

# 2. 공원에서 하는 활동

## 질문

- What do you usually do at the park?
- Tell me about your routine when you go to a park.

## Script

I usually go / to North Port Waterfront Park / near my home, / and the main thing I do there / is exercise.

I like working out / early in the morning, / so I often go there alone. / Honestly, / most of my friends don't want / to wake up at 5:30 in the morning / just to exercise with me.

My usual routine / is pretty simple. / First, / I run about three kilometers / on the running path, / which takes me / around fifteen minutes. / If I still have some energy left, / I use the outdoor workout machines / for a little while.

After that, / I stretch my arms and legs / and cool down. / Sometimes / I grab an energy drink / on my way home.

When the weather is nice / in spring, / I also go there / with friends or family / just to take a walk.

I really like exercising there / because being outdoors / feels much more refreshing / than running on a treadmill.

## 뜻

나는 보통 가 / 집 근처 북항친수공원에, / 그리고 거기서 가장 많이 하는 활동은 / 운동이야.

나는 운동하는 걸 좋아해 / 아침 일찍, / 그래서 혼자 가는 경우가 많아. / 솔직히, / 대부분의 친구들은 원하지 않아 / 새벽 5시 30분에 일어나는 걸 / 나와 같이 운동하려고.

내 운동 루틴은 / 꽤 단순해. / 먼저, / 약 3km를 뛰어 / 러닝 코스에서, / 대략 걸려 / 15분 정도. / 아직 힘이 남아 있으면, / 야외 운동기구도 사용해 / 잠깐.

그다음, / 팔과 다리를 스트레칭하고 / 몸을 식혀. / 가끔은 / 에너지 드링크를 사기도 해 / 집에 돌아가는 길에.

날씨가 좋을 때는 / 봄에, / 친구나 가족과도 가 / 그냥 산책하러.

공원에서 운동하는 걸 정말 좋아해 / 야외에 있는 게 / 훨씬 더 상쾌하게 느껴지기 때문이야 / 러닝머신에서 뛰는 것보다.
