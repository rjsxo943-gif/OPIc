# 캠핑 — 75초 버전

> 목표: 각 답변 약 65~85초

---

# 1. 해변 캠핑에 가져가는 물건

## 질문
- What do you usually bring when you go camping near the beach?
- Tell me about the things you pack for a camping trip.

## Script
When I go camping near the beach, / I usually go with three close friends / and stay for one night.

We try to bring / only the things we really need. / The main items are / a tent, / sleeping bags, / camping chairs, / and a small table.

I also pack / a change of clothes, / towels, / comfortable shoes, / and sometimes a swimsuit / because the campsite is close to the beach.

For food, / we bring simple meals, / snacks, / and plenty of bottled water. / I also make sure to take / sunscreen / and a portable charger.

One thing we always bring / is a Bluetooth speaker / because we enjoy listening to music / while relaxing together.

It still sounds like a lot, / but we divide everything / among four people, / so it's easy enough to carry / and makes the trip / much more comfortable.

## 뜻
해변 근처로 캠핑을 갈 때는, / 보통 친한 친구 세 명과 함께 가고 / 1박을 해.

우리는 챙기려고 해 / 정말 필요한 것만. / 가장 중요한 물건은 / 텐트, / 침낭, / 캠핑 의자, / 작은 테이블이야.

또 챙기는 건 / 갈아입을 옷, / 수건, / 편한 신발, / 그리고 가끔 수영복이야 / 캠핑장이 해변과 가깝기 때문이야.

음식은 / 간단한 식사와, / 간식, / 생수를 충분히 챙겨. / 또 꼭 챙기는 건 / 선크림과 / 보조배터리야.

항상 가져가는 것 중 하나는 / 블루투스 스피커야 / 함께 쉬면서 / 음악 듣는 걸 좋아하거든.

그래도 짐이 많아 보이지만, / 네 명이 나눠서 들기 때문에, / 충분히 들고 갈 수 있고 / 여행도 / 훨씬 편해져.

# 2. 기억에 남는 캠핑 경험

## 질문
- Tell me about a memorable camping trip.
- Describe the last time you went camping.

## Script
The last time I went camping / was earlier this summer. / I went on a two-day, one-night trip / with three of my close friends / to a campsite / near Songjeong Beach in Busan.

We had all been busy and tired, / so we wanted / a relaxing weekend. / The weather was warm and sunny, / and there was / a cool ocean breeze.

When we arrived, / we set up our tent, / chairs, / and table. / Setting up the tent / was harder than we expected, / so all four of us / had to work together.

After that, / we walked along the beach, / took pictures, / and listened to the waves. / In the evening, / we ate dinner together / while watching the sunset.

Later, / we sat outside the tent, / listened to music, / and talked for hours.

It was only a short trip, / but spending time with my friends / and falling asleep / to the sound of the waves / made it really memorable. / I'd definitely like / to go again.

## 뜻
마지막으로 캠핑을 간 건 / 올해 초여름이었어. / 친한 친구 세 명과 / 1박 2일 여행을 갔어 / 캠핑장으로 / 부산 송정해수욕장 근처에 있는.

우리 모두 바쁘고 지쳐 있어서, / 원했어 / 편하게 쉬는 주말을. / 날씨는 따뜻하고 맑았고, / 바다에서 / 시원한 바람이 불었어.

도착하자마자, / 텐트와, / 의자, / 테이블을 설치했어. / 텐트를 설치하는 게 / 생각보다 어려워서, / 네 명이 다 같이 / 해야 했어.

그다음에는, / 해변을 걷고, / 사진을 찍고, / 파도 소리를 들었어. / 저녁에는, / 함께 저녁을 먹으면서 / 일몰을 봤어.

밤에는, / 텐트 밖에 앉아, / 음악을 듣고, / 몇 시간 동안 이야기를 나눴어.

짧은 여행이었지만, / 친구들과 시간을 보내고 / 잠드는 경험이 / 파도 소리를 들으면서 / 정말 기억에 남았어. / 꼭 다시 / 가고 싶어.
