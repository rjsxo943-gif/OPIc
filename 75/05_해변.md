# 해변 — 75초 버전

> 목표: 각 답변 약 65~85초

# 1. 좋아하는 해변

## 질문

- Tell me about your favorite beach.
- Describe a beach you like to visit.

## Script

My favorite beach is Gwangalli Beach / in Busan. / I'm originally from Busan, / so I've visited many beaches there, / but Gwangalli is the one / I like the most.

It takes about thirty minutes / to get there by bus from my home, / so I can visit / without making a big plan. / I usually go with my friends / when the weather is nice.

During the day, / we spread out a picnic mat, / eat snacks, / talk, / or take a walk along the beach. / I really like listening / to the sound of the waves / because it helps me relax.

The best part / is the night view. / When it gets dark, / Gwangandaegyo Bridge lights up over the water, / and the whole area / looks beautiful.

I like Gwangalli / because it has both a lively city atmosphere / and a relaxing beach atmosphere. / Whenever I go there, / I can clear my head / and feel refreshed.

## 뜻

내가 가장 좋아하는 해변은 광안리해수욕장이야 / 부산에 있는. / 나는 원래 부산 출신이라 / 여러 해변에 가봤지만, / 그중에서도 광안리를 / 가장 좋아해.

집에서 버스로 약 30분 정도 걸려서 / 큰 계획 없이도 / 쉽게 갈 수 있어. / 날씨가 좋을 때는 / 보통 친구들과 가.

낮에는 / 돗자리를 펴고, / 간식을 먹거나, / 이야기를 하고, / 해변을 따라 산책해. / 파도 소리를 듣는 걸 정말 좋아하는데 / 마음이 편안해지기 때문이야.

가장 좋은 부분은 / 야경이야. / 밤이 되면 / 광안대교에 불이 들어오고, / 바다 위로 보이는 풍경이 / 정말 아름다워.

광안리는 / 활기찬 도시 분위기와 / 편안한 해변 분위기를 둘 다 느낄 수 있어서 좋아해. / 갈 때마다 / 머리를 식히고 / 상쾌한 기분을 느낄 수 있어.

# 2. 기억에 남는 해변 경험

## 질문

- Tell me about a memorable trip to the beach.
- Describe a memorable experience you had at a beach.

## Script

One of my most memorable trips to the beach / happened last summer.

One of my close friends / was feeling really tired, / so we suddenly decided / to go to Gwangalli Beach together. / We took a bus there / in the late afternoon, / and luckily, / the weather was perfect. / The sky was clear, / and there was a cool breeze / from the ocean.

We bought some beverages and snacks / from a convenience store, / spread out a picnic mat, / and talked for a long time. / Later, / we walked near the water / and took pictures of the sunset.

As it got darker, / Gwangandaegyo Bridge lit up, / so we sat on a bench / and watched the night view / while listening to the waves.

My friend looked much more relaxed / by the end of the day. / It wasn't an expensive or special trip, / but it became a meaningful memory / because we could forget about / our worries together.

## 뜻

가장 기억에 남는 해변 여행 중 하나는 / 지난여름에 있었어.

친한 친구 한 명이 / 많이 지쳐 있어서, / 갑자기 광안리에 / 같이 가기로 했어. / 늦은 오후에 버스를 타고 갔는데, / 다행히 / 날씨가 정말 좋았어. / 하늘이 맑았고 / 바다에서 시원한 바람이 불었어.

편의점에서 음료와 간식을 사고, / 돗자리를 편 뒤, / 오랫동안 이야기를 했어. / 그다음에는 / 물가를 따라 걸으면서 / 일몰 사진도 찍었어.

어두워지자 / 광안대교에 불이 들어왔고, / 우리는 벤치에 앉아 / 파도 소리를 들으며 / 야경을 봤어.

하루가 끝날 때쯤 / 친구는 훨씬 편안해 보였어. / 비싸거나 특별한 여행은 아니었지만, / 함께 걱정을 잊을 수 있어서 / 의미 있는 추억이 됐어.
