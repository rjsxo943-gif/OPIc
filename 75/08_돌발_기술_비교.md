# 돌발 — 과거와 현재 기술 비교 75초 버전

## 질문
- How has technology changed over the years?
- How is technology today different from the past?

## Script
Technology has changed a lot / since I was a child.

When I was younger, / my family mainly used / one desktop computer at home. / It was large, / slow, / and fixed in one place. / If someone else was using it, / I had to wait / for my turn. / I mostly used it / for simple games, / YouTube, / and school assignments.

These days, / things are completely different. / I have a smartphone / and a laptop, / so I can study, / communicate, / watch videos, / and search for information / almost anywhere. / I can also save files online / and open them / on different devices.

For me, / the biggest change / is mobility. / Technology is no longer something / I use only at a desk. / It's with me / almost all the time.

Of course, / people have become more dependent / on technology, / and it can be frustrating / when the internet is slow. / Still, / I prefer modern technology / because it saves time / and makes daily life / much more convenient.

## 뜻
기술은 정말 많이 변했어 / 내가 어렸을 때부터.

어릴 때는, / 우리 가족이 주로 사용했어 / 집에 있는 데스크톱 컴퓨터 한 대를. / 크고, / 느렸고, / 한 장소에 고정되어 있었어. / 다른 사람이 사용하고 있으면, / 기다려야 했어 / 내 차례를. / 나는 주로 사용했어 / 간단한 게임이나, / 유튜브, / 학교 과제를 할 때.

요즘은, / 상황이 완전히 달라. / 스마트폰과 / 노트북이 있어서, / 공부하고, / 연락하고, / 영상을 보고, / 정보를 찾을 수 있어 / 거의 어디서나. / 파일을 온라인에 저장하고 / 여러 기기에서 / 열 수도 있어.

내가 생각하는 / 가장 큰 변화는 / 이동성이야. / 이제 기술은 더 이상 / 책상 앞에서만 사용하는 것이 아니야. / 거의 항상 / 내 곁에 있어.

물론, / 사람들은 더 의존하게 됐어 / 기술에, / 그리고 답답할 때도 있어 / 인터넷이 느리면. / 그래도, / 나는 현대 기술이 더 좋아 / 시간을 절약하고 / 일상을 / 훨씬 편리하게 해주기 때문이야.
