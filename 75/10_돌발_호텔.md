# 1. 한국 호텔의 특징

## 질문
- Tell me about hotels in your country.
- What kinds of hotels are there in Korea?

## Script
There are many different kinds of hotels / in Korea, / so travelers can choose / based on their budget / and the purpose of their trip.

In large cities / like Seoul and Busan, / there are many business hotels / near subway stations, / train stations, / and shopping areas. / The rooms are usually not very large, / but they're clean / and have basic things / such as a comfortable bed, / a private bathroom, / Wi-Fi, / and toiletries.

There are also luxury hotels / with swimming pools, / fitness centers, / restaurants, / and great city views. / Outside major cities, / travelers can also find / pensions, / guesthouses, / and traditional hanok stays.

One thing I like / about hotels in Korea / is convenience. / There are usually restaurants, / cafés, / convenience stores, / and public transportation / nearby.

Overall, / Korean hotels are generally clean, / safe, / and easy to use, / and there are options / for many different budgets.

## 뜻
한국에는 다양한 종류의 호텔이 있어서 / 여행 목적과 / 예산에 맞게 / 선택할 수 있어.

서울이나 부산 같은 큰 도시에는 / 비즈니스호텔이 많아 / 지하철역이나, / 기차역, / 쇼핑 지역 근처에. / 객실은 아주 크지 않은 경우가 많지만 / 깨끗하고 / 필요한 기본적인 것들은 있어 / 편안한 침대, / 개인 욕실, / 와이파이, / 세면도구 같은.

고급호텔도 있어 / 수영장과, / 피트니스센터, / 식당, / 멋진 도시 전망이 있는. / 대도시 밖에서는 / 펜션이나, / 게스트하우스, / 전통 한옥 숙소도 찾을 수 있어.

내가 한국 호텔에서 좋아하는 점은 / 편리함이야. / 보통 근처에 / 식당, / 카페, / 편의점, / 대중교통이 있어.

전체적으로 / 한국 호텔은 대체로 깨끗하고, / 안전하고, / 이용하기 편하고, / 다양한 예산에 맞는 / 선택지가 있어.

# 2. 최근 호텔 숙박 경험 — 후쿠오카

## 질문
- Tell me about the last time you stayed at a hotel.
- Where did you stay and who were you with?

## Script
One of my recent hotel stays / was during a trip to Fukuoka / with three of my high school friends, / so there were four of us / in total.

We booked a hotel / in a convenient area / near public transportation / and many restaurants. / The room wasn't very large, / but it was clean / and comfortable enough / for us.

After checking in, / we dropped off our bags / and went straight outside. / We walked around the city, / visited shops, / and tried several local dishes.

After dinner, / we went back to the hotel / and stayed up late / talking about our high school days / and our current lives.

The room felt a little crowded / with four people, / but that actually made it / more fun. / The hotel wasn't luxurious, / but spending the night / talking and laughing / with old friends / made it memorable.

## 뜻
최근 호텔 숙박 경험 중 하나는 / 후쿠오카 여행 때였어 / 고등학교 친구 세 명과 함께, / 그래서 총 / 네 명이었어.

호텔을 예약했어 / 편리한 지역에 / 대중교통과 / 식당이 많은 곳 근처에. / 방은 아주 크지는 않았지만 / 깨끗했고 / 충분히 편했어 / 우리에게.

체크인한 뒤 / 짐만 내려놓고 / 바로 밖으로 나갔어. / 도시를 걸어 다니고, / 상점도 구경하면서, / 여러 현지 음식도 먹어봤어.

저녁을 먹고 / 호텔로 돌아온 뒤에는 / 늦게까지 이야기했어 / 고등학교 시절과 / 지금 사는 이야기를.

네 명이 있어서 / 방은 조금 좁게 느껴졌지만 / 오히려 그게 / 더 재미있었어. / 호텔 자체가 고급스러웠던 건 아니지만 / 밤늦게까지 / 웃고 이야기한 시간이 / 오랜 친구들과 함께여서 / 기억에 남았어.

# 3. 기억에 남는 호텔 경험 — 홍콩

## 질문
- Tell me about a memorable hotel experience.
- What made the hotel stay memorable?

## Script
One of my most memorable hotel experiences / happened during a trip to Hong Kong / with a close friend.

Our trip was short, / so we chose a hotel / in a convenient area / near public transportation / and major tourist spots. / When we entered the room, / I was surprised / by how small it was. / Hong Kong was more expensive / than Korea, / so the room was smaller / than I expected / for the price.

Still, / it was clean, / the bed was comfortable, / and the location was excellent. / We could easily get / to Tsim Sha Tsui / and Victoria Harbour.

During the day, / we walked around busy streets, / visited shops, / and tried local food. / At night, / we went to Victoria Harbour / and looked at the bright skyline / across the water.

After walking for hours, / we went back to the hotel, / bought some snacks, / and talked about / what we had seen.

The hotel wasn't luxurious, / but its location / made the short trip easy / and became part of my memory / of Hong Kong's bright / and energetic atmosphere.

## 뜻
내가 가장 기억에 남는 호텔 경험 중 하나는 / 홍콩 여행 때였어 / 친한 친구와 함께.

여행이 짧아서 / 호텔을 잡았어 / 편리한 지역에 / 대중교통과 / 주요 관광지에 가까운. / 방에 처음 들어갔을 때 / 놀랐어 / 생각보다 너무 작아서. / 홍콩은 물가가 더 비싸서 / 한국보다, / 방도 더 작았어 / 내가 예상했던 것보다 / 그 가격에 비해서.

그래도 / 깨끗했고, / 침대도 편했으며, / 위치가 정말 좋았어. / 쉽게 갈 수 있었어 / 침사추이와 / 빅토리아 하버까지.

낮에는 / 붐비는 거리를 걸어 다니고, / 상점을 구경하면서, / 현지 음식을 먹었어. / 밤에는 / 빅토리아 하버에 가서 / 빛나는 스카이라인을 봤어 / 물 건너편으로.

몇 시간 동안 돌아다닌 뒤 / 호텔로 돌아와, / 간식을 사 먹으면서, / 이야기했어 / 그날 본 것들에 대해.

호텔 자체가 고급스럽지는 않았지만 / 좋은 위치 덕분에 / 짧은 여행이 훨씬 편했고 / 내 기억의 일부가 됐어 / 홍콩의 밝고 / 활기찬 분위기와 함께.
