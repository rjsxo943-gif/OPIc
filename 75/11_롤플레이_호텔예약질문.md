# 롤플레이 — 호텔 예약에 대해 질문하기

## 상황
휴가를 위해 호텔에 전화해서 객실 가능 여부, 종류와 가격, 결제, 취소 규정을 묻는다.

## Script
Hello, / is this the Grand Hotel? / I'm planning a trip / and I'd like to book a room. / I have a few questions / before I make the reservation.

First, / do you have any rooms available / from August 15th to August 18th? / Oh, you do? / That's great.

I'm traveling with a friend, / so what kind of room / would you recommend / for two people? / And how much is it / per night? / I see. / A twin room sounds good.

One more thing. / Do I need to pay / when I make the reservation, / or can I pay / when I check in? / Okay, / that's convenient.

Finally, / could you tell me / about your cancellation policy? / Can I cancel / without a fee / if my plans change?

I understand. / Thank you / for all the information. / I'll talk to my friend / and call you back / to make the reservation. / Thanks again. / Bye!

## 뜻
안녕하세요, / 그랜드 호텔 맞나요? / 여행을 계획하고 있어서 / 객실을 예약하려고 하는데요. / 몇 가지 질문이 있습니다 / 예약하기 전에.

먼저, / 8월 15일부터 18일까지 / 이용할 수 있는 방이 있나요? / 아, 있나요? / 좋네요.

친구 한 명과 같이 갈 건데, / 어떤 방을 / 추천하시나요 / 두 명에게? / 그리고 가격은 얼마인가요 / 1박에? / 그렇군요. / 트윈룸이 괜찮겠네요.

한 가지 더요. / 바로 결제해야 하나요 / 예약할 때, / 아니면 결제해도 되나요 / 체크인할 때? / 알겠습니다. / 편리하네요.

마지막으로, / 알려주실 수 있을까요 / 취소 규정을? / 취소할 수 있나요 / 수수료 없이 / 계획이 바뀌면?

알겠습니다. / 감사합니다 / 정보 알려주셔서. / 친구와 이야기해 보고 / 다시 전화드릴게요 / 예약하려고. / 감사합니다. / 안녕히 계세요.
