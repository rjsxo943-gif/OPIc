# 롤플레이 — 잘못된 가구가 배송된 상황

## 상황
검정색 침대와 회색 소파를 주문했는데 다른 제품이 배송됐다.

## Script
Hello, / I'm calling because there's a problem with my order.

I ordered a black bed and a gray sofa, / but I received the wrong items. / The bed is white, / and the sofa is a different model.

Could you please pick them up / and send me the correct items? / If they're not available right away, / when is the earliest you can deliver them? / I can wait a few days, / but I need them as soon as possible.

If you can't replace the bed, / I'd like a full refund instead. / As for the sofa, / I could keep the one I received / if you can give me a reasonable discount.

Could you please check my order / and let me know what you can do? / I'd also like to know / when the wrong items can be picked up.

Thank you for your help. / I hope we can solve this / as soon as possible.

## 뜻
안녕하세요. / 제 주문에 문제가 있어서 전화드렸습니다.

검정색 침대와 회색 소파를 주문했는데, / 잘못된 제품을 받았어요. / 침대는 흰색이고, / 소파는 다른 모델이에요.

잘못 온 제품을 회수하고 / 제가 주문한 제품으로 보내주실 수 있나요? / 바로 준비가 안 된다면, / 가장 빠른 배송일이 언제인가요? / 며칠 정도는 기다릴 수 있지만, / 가능한 한 빨리 필요합니다.

침대를 교환할 수 없다면, / 전액 환불을 받고 싶어요. / 소파는, / 적당한 할인을 해주신다면 / 지금 받은 제품을 그냥 사용하는 것도 괜찮습니다.

제 주문을 확인해서 / 어떤 해결이 가능한지 알려주실 수 있을까요? / 잘못 온 제품을 / 언제 회수할 수 있는지도 알고 싶습니다.

도와주셔서 감사합니다. / 가능한 한 빨리 / 해결됐으면 좋겠습니다.
