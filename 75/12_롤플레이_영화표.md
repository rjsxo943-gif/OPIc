# 롤플레이 — 영화표를 잘못 구매한 상황

## 상황
오늘 밤 영화표를 실수로 샀지만 실제로 필요한 것은 내일 표다.

## Script
Excuse me. / I have a problem / with my movie tickets.

I accidentally bought two tickets / for tonight, / but I actually need them / for tomorrow. / Would it be possible / to change the tickets / to tomorrow's show? / Any evening time / would be fine for me, / so I'm flexible / about the exact time.

If I can't change them directly, / is there another way / to move the tickets / to tomorrow? / I can choose / a different showtime / if necessary.

If that still isn't possible, / could you tell me / what other options I have? / I'm flexible, / so I'd be happy / with any reasonable solution.

I'm sorry / about the mistake. / Could you please check the tickets / and tell me / what I can do?

Thank you / for your help. / I really appreciate it.

## 뜻
실례합니다. / 문제가 있습니다 / 제 영화표에.

제가 실수로 표 두 장을 샀는데 / 오늘 밤 것으로, / 실제로 필요한 건 / 내일 표예요. / 가능할까요 / 표를 변경하는 것이 / 내일 상영으로? / 저녁 시간이라면 / 아무 때나 괜찮아서, / 정확한 시간은 / 유동적으로 맞출 수 있어요.

바로 변경할 수 없다면, / 다른 방법이 있을까요 / 표를 / 내일로 옮길 수 있는? / 필요하다면 / 다른 상영 시간도 / 선택할 수 있어요.

그것도 어렵다면, / 알려주실 수 있을까요 / 다른 가능한 방법을? / 저는 유동적으로 맞출 수 있어서, / 괜찮은 해결책이라면 / 어떤 방법이든 / 괜찮습니다.

죄송합니다 / 제가 실수해서. / 표를 확인해 보시고 / 알려주실 수 있을까요 / 어떻게 하면 되는지?

감사합니다 / 도와주셔서. / 정말 감사해요.
