### 질문형 공통 순서

`상황 설명 → 질문 1 → 반응 → 질문 2 → 반응 → 질문 3~4 → 감사`

### 반드시 익힐 표현

- `Could I ask you a few questions?`
- `First of all, ...?`
- `Also, ...?`
- `One more thing. ...?`
- `Finally, ...?`
- `That is good to know.`

### 문제 해결 공통 순서

`문제 설명 → 가장 원하는 해결책 → 대안 2 → 대안 3 → 확인 요청 → 감사`

### 반드시 익힐 표현

- `There seems to be a problem with...`
- `Would it be possible to...?`
- `If that is not possible, could you...?`
- `If neither option works, I could...`
- `That would work for me.`
- `Please check and let me know.`
